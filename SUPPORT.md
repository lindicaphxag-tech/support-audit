# Support and governance

## Maintainer

Zhibo Zhang (`@lindicaphxag-tech`), Hangzhou Dianzi University.

## Where to ask

- Bug reports and reproducibility questions: open a GitHub issue.
- Security or private data concerns: email `24061721@hdu.edu.cn` instead of opening a public issue.

## Response policy

The maintainer aims to acknowledge reproducible bug reports within seven days and to provide either a fix, a minimal workaround, or a clear statement that the issue is out of scope. This is a single-maintainer project; there is no 24/7 service-level guarantee.

## Scope of support

Supported: installation, CLI contract, CSV schema, calibration layout, numerical diagnostics, and test failures.

Not supported: clinical validation, distribution-free coverage claims, fine-tuning recipes, or benchmark leaderboard disputes.

## Release and citation

Releases are tagged on GitHub. Use `CITATION.cff` for citation metadata. The reviewed software version for the MLOSS submission is v0.1.0.
